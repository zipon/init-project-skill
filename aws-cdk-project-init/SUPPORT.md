# Support

AWS CDK Project Init is maintained by Lars Andersson on a best-effort basis. There is no guaranteed response time or service-level agreement.

## Public support URL

Use the repository's public issue tracker:

https://github.com/zipon/aws-skill-project/issues

Before opening an issue, include the operating system, Node.js version, npm version, the step that failed, and the complete non-sensitive error message. Never post AWS account IDs, credentials, tokens, repository secrets, private source code, or other sensitive information.

For a security-sensitive report, use the repository's private vulnerability reporting feature when enabled. Do not disclose the issue in a public ticket.

Support covers the initializer and its bundled workflow. AWS account access, IAM policy design, GitHub organization policies, CDK bootstrap administration, generated application behavior, and cloud charges remain the user's responsibility.
